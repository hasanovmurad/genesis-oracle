# Genesis Oracle

Genesis Oracle is a semester-long engineering project developed for the course **Angewandte Modellierung und Systemsimulation (SoSe 2026)**.

The project explores the transition from classical physical simulation to AI-assisted autonomous systems by combining numerical modeling, machine learning, stochastic simulation, agentic workflows, and retrieval-augmented reasoning.
